# ザクロの継承 (Zakuro Online)

先代のボスが死んだ。遺された黒い袋が、幹部たちの手を巡る——。
友人と通話しながらブラウザで遊ぶ、4〜8人・約15分の心理戦ゲームです。
Next.js (App Router) + Socket.io によるリアルタイム対戦。

## ローカル開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。カスタムサーバー(`server.ts`)が
Next.jsとSocket.ioを同一プロセス・同一ポートで提供します(`next dev`単体では動きません)。

### 1人でテストする

部屋を作ってから、別ターミナルでボットを参加させられます(ランダムに行動します)。

```bash
npx tsx scripts/bots.ts <部屋コード> 3
```

ルール処理だけを大量のランダム対戦で検証するには:

```bash
npx tsx scripts/simulate.ts 3000
```

## ゲームルール実装メモ

- 4〜8人。継承順位(1〜人数)はゲーム開始時にランダムで割り振り、常に全員に表示
- 3セット制。各セットは 指輪による指名 → 経済フェーズ → (内偵) → 戦闘フェーズ
  - 経済: 第1セット1個取る / 第2セット1個(または2個取って手番前からの手持ちを1個戻す) / 第3セット2個(または3個取って1個戻す)
  - 袋の総数: 第1・2セット=参加人数+1、第3セット=参加人数×2+2(指輪が袋にある場合は指輪を含む)。脱落者が出ても最初の人数基準
  - 袋は毎セット作り直し。宝石は必ず2個以上、宝石・銃・弾丸・人形のうち欠けるのは最大1種類(`generateBag`)
  - 戦闘: 経済と同じ順番で各自1回。銃+弾丸で撃てる(弾1消費)。人形1体で1発防ぐ。死亡したら撃った者が全所持品を奪う
- ザクロの指輪: ゲームに1個。持ち主は公開。各セット開始時にスタートを指名(袋の中身公開前)。終了時に宝石1個分
  - 持ち主がいなければ前回と同じスタート(死亡していれば次の番号の生存者)
- 偽物: 本人以外は区別できない。偽銃=不発して破棄(弾は残る)、偽弾=不発して消費、偽人形=防げず破棄(本物があればそれで防ぐ)。袋に残った偽物はセット終了で消える
- 勝敗: 生存者の 宝石+指輪+秘密ボーナス の合計 → 指輪 → ボーナス達成 → 継承順位 の順。生存者が1人になったら即勝利
- 役職(公開)は `lib/content.ts` の `ROLES`、秘密ボーナスは `BONUSES`。判定は `lib/gameEngine.ts` の `bonusAchieved`
- 死亡者が全員の手の内を観戦できるかはロビーでホストが切り替え可能
- 部屋の状態はサーバーのメモリ内で管理(`lib/rooms.ts`)。プロセス再起動で消えます

## クラウドデプロイ

WebSocketを使い続けるため、常駐プロセスを実行できるホスティング(Railway, Render, Fly.ioなど)が必要です。

付属の `Dockerfile` を使ってデプロイできます:

```bash
docker build -t zakuro-online .
docker run -p 3000:3000 zakuro-online
```

Railway の場合は、GitHubリポジトリを接続すれば Dockerfile が自動検出されます。
`PORT` 環境変数はホスティング側が自動設定するものをそのまま使えます。
